# 生日快乐 · 网页小解谜

一个四幕式的生日小游戏，双击 `index.html` 就能玩。

**流程：密码锁 → 抽 5 支祝福签 → 21 根蜡烛一根根吹灭 → 陷入黑暗 → 手机聊天 → 退出**

---

## 一、怎么打开

双击文件夹里的 **`index.html`**，用 Chrome / Edge 打开即可（手机也能玩，浏览器打开就行）。

> 如果不能双击打开，右键 → 打开方式 → Google Chrome。

---

## 二、文件都是干嘛的

| 文件 | 作用 | 要不要改 |
|---|---|---|
| `index.html` | 页面骨架（四个场景、蛋糕、手机） | 一般不用动 |
| `style.css` | 全部配色和动画 | 想换颜色、换风格再动 |
| `game.js` | 主流程：解锁 → 抽签 → 吹蜡烛 → 聊天 | 一般不用动 |
| **`password.js`** | **密码锁的规则** | **★ 你自己写** |
| **`chat.js`** | **黑暗里的聊天内容** | **★ 你自己写** |
| `blessings.js` | 20 条祝福语 | 想换词就改 |

---

## 三、改密码（`password.js`）

打开 `password.js`，最简单的改法只动两行：

```js
length: 4,          // 密码几位
answer: '0824',     // 正确答案，改成你想要的
```

顺便把上面的 `hint`（提示小字）改成对应的说法，别把答案直接写出来 😉

**想玩花样**：不用 `answer`，改 `verify(input)` 这个函数，返回 `true` 就算密码正确。文件里已经留了 5 种写法的例子（比大小写、多个答案都对、计算题、日期题……），把注释打开、把默认那行删掉即可。

改完保存，刷新网页就生效。

## 四、改聊天（`chat.js`）

台词都在 `messages` 数组里，一条一条往下排：

```js
{ from: 'them', text: '对方说的话', delay: 1500 },
```

- `from`：`'them'` 左边（对方）／`'me'` 右边（自己，蓝色气泡）／`'sys'` 居中的灰色小字
- `delay`：这条出现前等多少毫秒，`1000` = 1 秒；对方消息会先显示"正在输入…"
- 想换行就在文字里写 `\n`

同一个文件里还能改：对方的名字 `contact`、头像 emoji `avatar`、输入框灰字 `placeholder`，以及点"退出"之后的结束语 `endTitle` / `endText`。

> `exitAction` 默认是 `'ending'`（显示结束语 + 撒花）。
> 改成 `'close'` 会尝试直接关掉窗口（只对用 `window.open` 打开、或用某些浏览器打开的情况有效，所以默认没用它）。

## 五、自己调试的小技巧

改完想知道效果，不用从头玩一遍。在网址后面加参数就行：

| 网址后面加 | 效果 |
|---|---|
| `?stage=draw` | 直接跳到抽签 |
| `?stage=cake` | 直接跳到蛋糕 |
| `?stage=dark` | 直接跳到聊天 |
| `?dev=1` | 左下角出现四个跳转按钮 |

举例：`index.html?stage=cake`

（本地双击打开时，也可以直接在地址栏里手打。）

## 六、玩的时候

- 右上角 🔊 可以静音；音效是代码现场合成的，没有音频文件，不占体积。
- 抽签每次从 20 条里随机抽 5 条，**不会重复**。
- 蜡烛点一下灭一根，也可以对着画面空白处点；21 根全灭后会黑屏几秒，然后手机亮起来。
- 聊天播完后点「退出」出现结束语。
